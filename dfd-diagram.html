4. Diagram Hubungan Antardata (Entity Relationship Diagram)

Relasi antar tabel/koleksi Firestore: users, attendance, settings, dan deleted_accounts

erDiagram
    USERS ||--o{ ATTENDANCE : "melakukan (1 to N)"
    SETTINGS_GEOFENCE ||--o{ ATTENDANCE : "memvalidasi (1 to N)"
    USERS ||--o| DELETED_ACCOUNTS : "dicatat (1 to 1)"

    USERS {
        string uid PK "ID Unik Firebase Auth"
        string name "Nama Lengkap Karyawan"
        string email "Alamat Email Terdaftar"
        string department "Divisi atau Departemen"
        string role "Hak Akses admin atau karyawan"
        string status "Status aktif atau nonaktif"
        timestamp createdAt "Waktu Akun Dibuat"
    }

    ATTENDANCE {
        string id PK "ID Transaksi Absensi"
        string uid FK "Foreign Key ke USERS"
        string type "Check In atau Check Out"
        string status "Hadir atau Terlambat atau Ditolak"
        string date "Tanggal YYYY-MM-DD"
        int distanceMeters "Jarak ke Kantor Meter"
        float lat "Latitude GPS Perangkat"
        float lng "Longitude GPS Perangkat"
        timestamp timestamp "Waktu Server Presisi"
    }

    SETTINGS_GEOFENCE {
        string id PK "ID Konfigurasi geofence"
        string name "Nama Kantor Acuan"
        float lat "Latitude Pusat Kantor"
        float lng "Longitude Pusat Kantor"
        int radius "Batas Radius Absensi Meter"
        string workStart "Jam Acuan Masuk HH:mm"
        string workEnd "Jam Acuan Pulang HH:mm"
        int lateGraceMinutes "Toleransi Terlambat Menit"
    }

    DELETED_ACCOUNTS {
        string uid PK "ID Akun Terhapus"
        string name "Nama Karyawan"
        string email "Alamat Email"
        timestamp deletedAt "Waktu Penghapusan"
        string deletedBy "Admin Penghapus Akun"
    }

6. Rujukan Flowchart Sistem (System Flowchart)

Alur logika komprehensif dari awal login, validasi GPS & geofencing, hingga pelaporan

flowchart TD
    Start([Mulai]) --> OpenApp[Buka Aplikasi Web AbsensiGeo]
    OpenApp --> LoginInput[/Input Email dan Password/]
    LoginInput --> AuthCheck{Validasi Firebase Auth}
    
    AuthCheck -->|Gagal| LoginErr[Tampilkan Pesan Error]
    LoginErr --> LoginInput
    
    AuthCheck -->|Berhasil| CheckDeleted{Akun Terhapus atau Diblokir?}
    CheckDeleted -->|Ya| BlockAccess[Tolak Akses & Logout Otomatis]
    BlockAccess --> LoginInput
    
    CheckDeleted -->|Tidak| CheckRole{Cek Role Pengguna}
    
    CheckRole -->|Karyawan| DashKaryawan[Dashboard Karyawan]
    DashKaryawan --> ActionUser{Pilih Menu}
    
    ActionUser -->|Presensi| GetGPS[Deteksi Koordinat GPS Perangkat]
    GetGPS --> CalcHaversine[Hitung Jarak Haversine ke Titik Kantor]
    CalcHaversine --> CheckRadius{Jarak <= Radius?}
    
    CheckRadius -->|Tidak| RejectAbsen[Set Status: Ditolak]
    CheckRadius -->|Ya| CheckLate{Waktu Masuk <= Jam Masuk + Toleransi?}
    
    CheckLate -->|Ya| HadirAbsen[Set Status: Hadir]
    CheckLate -->|Tidak| LateAbsen[Set Status: Terlambat]
    
    RejectAbsen --> SaveAtt[(Simpan ke Firestore: attendance)]
    HadirAbsen --> SaveAtt
    LateAbsen --> SaveAtt
    SaveAtt --> NotifAbsen[Tampilkan Toast Hasil & Update UI]
    NotifAbsen --> DashKaryawan
    
    ActionUser -->|Riwayat| ViewHistory[Pilih Bulan & Buka Riwayat Presensi]
    ViewHistory --> ExportReport{Cetak atau Unduh PDF?}
    ExportReport -->|Ya| GenPDF[Generate Dokumen via html2pdf]
    ExportReport -->|Tidak| DashKaryawan
    GenPDF --> DashKaryawan
    
    ActionUser -->|Logout| DoLogout[Sign Out Sesi]
    
    CheckRole -->|Admin| DashAdmin[Dashboard Admin]
    DashAdmin --> ActionAdmin{Pilih Modul Admin}
    
    ActionAdmin -->|Kelola Karyawan| ModulUser[Tambah / Ubah Role / Hapus Akun Karyawan]
    ModulUser --> SaveUser[(Update Firestore: users)]
    SaveUser --> DashAdmin
    
    ActionAdmin -->|Pengaturan Geofence| ModulGeo[Atur Titik Kantor / Lokasi Saat Ini / Radius / Jam Kerja]
    ModulGeo --> SaveGeo[(Update Firestore: settings/geofence)]
    SaveGeo --> DashAdmin
    
    ActionAdmin -->|Laporan Bulanan| ModulReport[Filter Karyawan & Bulan -> Rekap Kehadiran]
    ModulReport --> PrintReport[Cetak / Unduh PDF Laporan Rekap]
    PrintReport --> DashAdmin
    
    ActionAdmin -->|Logout| DoLogout
    
    DoLogout --> End([Selesai])
